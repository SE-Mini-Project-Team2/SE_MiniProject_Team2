# NFR-05 — Browser Compatibility Test Report

## Objective
Verify that the Online Bookstore works correctly in supported desktop browsers.

## Test Environment
- Operating system: Windows
- Application: Django Online Bookstore
- Browsers tested: Google Chrome, Mozilla Firefox, Microsoft Edge
- Browser versions: Record the versions used during testing

## Test Results

| Test Case | Chrome | Firefox | Edge |
|---|---|---|---|
| Homepage and navigation | Pass | Pass | Pass |
| Browse books | Pass | Pass | Pass |
| Search by title and author | Pass | Pass | Pass |
| Search with no results | Pass | Pass | Pass |
| Seller adds a book | Pass | Pass | Pass |
| Customer cannot add a book | Pass | Pass | Pass |
| Login and logout | Pass | Pass | Pass |
| Forms and layout | Pass | Pass | Pass |

## Outcome
The tested workflows worked correctly in the three browsers listed above. No compatibility issues were observed during the recorded tests.

## Limitations
These results apply only to the browser versions and environment tested. They do not establish compatibility with every browser, device, or screen size.
